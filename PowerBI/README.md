📊 Fashion Boutique Sales Dashboard using Power BI

📌 Project Overview

This project presents an interactive Fashion Boutique Sales Dashboard developed using Microsoft Power BI.

The dashboard provides visual insights into fashion product sales, categories, brands, seasons, pricing, discounts, and sales trends.


🎯 Objectives

- Analyze fashion boutique sales performance
- Monitor key sales KPIs
- Analyze product and category performance
- Compare brand performance
- Analyze seasonal trends
- Understand pricing and discount patterns
- Create an interactive business dashboard


🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization


📊 Dashboard Analysis

The dashboard focuses on:

- Sales Performance
- Product Performance
- Category Analysis
- Brand Analysis
- Seasonal Analysis
- Price Analysis
- Discount Analysis
- Monthly Sales Trends


🎛️ Interactive Features

- Slicers
- Filters
- Interactive Charts
- KPI Cards
- Cross-filtering
