🐍 Fashion Boutique Sales Analysis using Python

📌 Project Overview

This project performs data analysis and visualization on fashion boutique sales data using Python. The analysis focuses on understanding product, category, brand, pricing, discount, seasonal, and monthly trends.

The analysis was performed using Google Colab.


🛠️ Tools & Libraries

- Google Colab
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn


📊 Analysis Performed

- Data Loading
- Data Cleaning
- Data Inspection
- Exploratory Data Analysis (EDA)
- Descriptive Statistics
- Product Analysis
- Category Analysis
- Brand Analysis
- Season Analysis
- Price Analysis
- Discount Analysis
- Monthly Analysis



📈 Data Visualization

The project uses Matplotlib and Seaborn to create visualizations for exploring patterns and trends in the fashion boutique sales data.
