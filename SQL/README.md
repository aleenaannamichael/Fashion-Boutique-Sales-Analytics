🗄️ Fashion Boutique Sales Analysis using MySQL

📌 Project Overview

This project performs sales and product analysis for a fashion boutique using MySQL. SQL queries are used to analyze pricing, discounts, brands, categories, seasons, colors, and monthly sales performance.

🛠️ Tool Used

- MySQL Workbench
- SQL

🗃️ Database

Database Name:

`fashion_boutique`

Main Table:

`fashion_sales`

The table contains information such as:

- Product_ID
- Category
- Brand
- Season
- Size
- Color
- Original_Price
- Markdown_Percentage
- Current_Price
- Discount_Amount
- Price_Category
- Purchase_Date
- Purchase_Month

📊 SQL Analysis

The project includes analysis of:

- Total Revenue
- Average Selling Price
- Total Discount
- Highest and Lowest Price
- Revenue by Category
- Revenue by Brand
- Orders by Season
- Monthly Revenue
- Products by Price Category
- Average Price by Brand
- Top 5 Brands
- Color-wise Product Count

💡 Advanced SQL Concepts

The project also demonstrates:

- Aggregate Functions
- GROUP BY
- HAVING
- ORDER BY
- Subqueries
- Views
- Window Functions
- RANK()
- DENSE_RANK()
