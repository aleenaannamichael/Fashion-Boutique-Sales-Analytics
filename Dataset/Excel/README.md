📊 Fashion Boutique Sales Analysis using Microsoft Excel

📌 Project Overview

This project analyzes fashion boutique sales data using Microsoft Excel. The workbook includes data analysis, KPI calculations, Pivot Tables, and an interactive dashboard to identify product, brand, category, pricing, discount, and seasonal trends.

🛠️ Tools & Features

- Microsoft Excel
- Data Cleaning
- Pivot Tables
- Pivot Charts
- KPI Analysis
- Dashboard
- Slicers
- Data Visualization

📊 Analysis Areas

- Product Performance
- Category Analysis
- Brand Analysis
- Season Analysis
- Price Analysis
- Discount Analysis
- Monthly Sales Analysis

📈 Dashboard

The Excel dashboard provides a visual summary of the fashion boutique sales data using KPIs and charts.
