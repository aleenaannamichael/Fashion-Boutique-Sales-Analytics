# 📂 Fashion Boutique Sales Dataset

## 📌 Overview

This folder contains the dataset used for the Fashion Boutique Sales Analytics project.

The dataset contains fashion product and sales information used for data cleaning, analysis, visualization, and dashboard development.

---

## 📊 Dataset Information

The dataset includes fields such as:

- Product ID
- Category
- Brand
- Season
- Size
- Color
- Original Price
- Markdown Percentage
- Current Price
- Discount Amount
- Price Category
- Purchase Date
- Purchase Month

---

## 🛠️ Used For

The dataset is used across:

- Microsoft Excel
- MySQL Workbench
- Python
- Power BI
