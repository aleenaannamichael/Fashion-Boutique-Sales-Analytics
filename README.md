👗 Fashion Boutique Sales Analytics

📌 Project Overview

This project is an end-to-end Sales Analytics project based on a fashion boutique dataset. The project demonstrates the complete data analytics workflow using Microsoft Excel, MySQL, Python, and Power BI.

The analysis focuses on product performance, brand performance, pricing, discounts, seasons, categories, and sales trends.


🎯 Project Objectives

- Clean and prepare fashion sales data
- Analyze product and brand performance
- Analyze pricing and discount patterns
- Identify category and seasonal trends
- Perform SQL-based business analysis
- Conduct exploratory data analysis using Python
- Build interactive Excel and Power BI dashboards
- Generate meaningful business insights


🛠️ Tools & Technologies

- Microsoft Excel – Data Cleaning, Pivot Tables, KPI Analysis & Dashboard Creation
- MySQL Workbench – Database Creation and SQL-Based Business Analysis
- Python – Data Cleaning, Exploratory Data Analysis (EDA) & Visualization
- Pandas – Data Manipulation and Data Analysis
- NumPy – Numerical Analysis and Data Processing
- Matplotlib – Data Visualization and Chart Creation
- Seaborn – Statistical Data Visualization
- Power BI – Interactive Dashboard Creation and Business Intelligence
